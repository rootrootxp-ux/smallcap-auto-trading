# Codex Arena スキルの使い方

このリポジトリの `.agents/skills/arena/SKILL.md` は、Codex用の**プロジェクト限定**カスタムスキルです。株価取得や売買コードは変更しません。

## 使い始める

1. この追加を `main` に取り込み、Codexで **smallcap-auto-trading** のプロジェクトを開き直す（または新しいタスクを開始する）。
2. Codexの入力欄で `$arena` を入力し、候補に表示されたら選択する。環境によっては `/skills` から確認できます。
3. 例：

   ```text
   $arena 小型株の空売り戦略を3案で比較。まだコードを書き換えず、
   現在の固定検証・別期間の制約とデータ品質の問題を踏まえて、
   評価基準、検証計画、失敗条件を示して。
   ```

`/arena` はCodexの標準スラッシュコマンドではありません。正規の呼び出しは `$arena` です。

## どこまで自動？

- 3案の作成・根拠・比較の定型化はこのスキルで指示できます。
- **本当に独立した3エージェントの並列実行**はCodexセッションにその機能が提供されている場合だけです。未対応時は単一モデルによる逐次比較であることを明示します。
- Claude/Gemini等の別会社のモデルに自動で依頼する機能は付いていません。
- 「利益が出た」「テストが通った」などは実測・実行できた場合だけ報告します。スキルを入れるだけではバックテストは走りません。
- 実売買注文、証券会社接続、勝手なコードマージは行いません。

## 検証例

```text
$arena 現在のデータ欠損処理について3つの設計案を比較し、
未決済ポジションの扱い、再現性、因果性、テストの難易度を評価して。
```

比較とバックテストの独立性は別です。過去に見て選んだ銘柄・期間だけで「優位性が実証された」とは判定できません。
