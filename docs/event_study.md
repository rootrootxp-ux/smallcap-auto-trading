# 保存済み5分足による空売り仮説のイベントスタディ

これは、事前に固定した条件の成立後に価格がどう変化したかを調べる記述的な研究です。空売り注文の実行、信用取引の再現、売買戦略の収益性判定、資金を共有するポートフォリオ計算は行いません。証券会社への接続や価格データのダウンロード機能もありません。

現在の50銘柄には現在の上場・時価総額・流動性情報で選んだ先読み・生存者バイアスがあります。保存された過去の価格で得られた結果を、未使用期間での検証や将来の収益性の証明として扱えません。

## 実行方法

Python 3.12で、リポジトリのルートから実行します。イベントスタディ自体は保存データだけを読みます。既存機能を含む自動テストのため、依存ライブラリは既存の固定ファイルからインストールします。

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m research.event_study
python -m research.event_study.check
```

既定入力は `research/event_study/saved_prices.zip` と `watchlist.csv`、出力先は `results/event_study/` です。保存データの来歴は `research/event_study/saved_source.json` に記録します。別の保存入力を検証するときは、入力を明示します。

```sh
python -m research.event_study \
  --prices path/to/saved_prices.zip \
  --watchlist path/to/watchlist.csv \
  --source-manifest path/to/source.json \
  --output results/event_study_custom
```

`--prices` は保存CSVのディレクトリまたはZIPです。閾値や期間をコマンドライン引数で変更する機能はありません。固定条件は `research/event_study/config.json` に保存し、出力のマニフェストにも条件とハッシュを残します。設定を変更した場合は別の仮説としてコード版・設定・入力を保存して比較してください。結果を見た後の条件変更を独立した検証とは呼べません。

## 固定した観測条件

次の5種類はそれぞれ独立したイベントです。条件を組み合わせた売買戦略ではありません。

| イベント名 | 確定済みの足だけによる定義 |
| --- | --- |
| `ma3_cross_down` | 前足終値が前足MA3以上、現在足終値が現在足MA3未満 |
| `vwap_cross_down` | 前足終値が前足VWAP以上、現在足終値が現在足VWAP未満 |
| `relative_volume_gt_1_5` | 現在足出来高が、現在足を除いた直前5本の平均出来高の1.5倍より大きい |
| `prior6_low_break` | 現在足終値が、現在足を除いた直前6本の最安値を下回る |
| `time_of_day` | 価格と正の出来高が確認できる全適格足を、観測開始の30分時間帯で分類 |

MAとVWAPの下抜けは「前足では以上、現在足では未満」というクロスを数えます。出来高増加と直前安値割れは条件が成立する各足の状態を数え、連続して成立しても重複排除しません。したがって連続する観測を別々の独立取引とは扱えません。

VWAPは当日内の足ごとの典型価格 `(High + Low + Close) / 3` を出来高で加重した近似値で、個々の約定から算出したVWAPではありません。観測開始は確定足の次の予定5分足始値、終端は開始から5分・15分・30分後の予定足始値に固定します。固定数量は100株、仮定手数料は片道100円です。費用込みでは片道スリッページ1円または2円を加えます。費用込みの概算損益は `(開始始値 − 終端始値) × 100株 − 2 × 片道スリッページ円 × 100株 − 200円` で、費用ゼロでは控除しません。収益率の分母は開始始値×100株です。信用保証金に対する収益率ではありません。これらの費用は研究用の仮定で、特定の証券会社の実料金ではありません。

## 時刻と欠損の扱い

足の時刻ラベルは区間の開始時刻です。ラベルが `t` の足は `t+5分` に確定し、観測開始には同じ `t+5分` の次足始値を使います。判定から観測開始まで遅延がない理想化であり、この始値で実際に約定できたことは保証しません。確定済み5分足だけでシグナルを判定し、確認足より前の価格で入ったことにはしません。各特徴量は当日内で計算し、出来高の比較対象5本と安値の比較対象6本には現在足を含めません。MA3は現在足を含む3本平均とし、前足では終値がMA以上、現在足ではMA未満になった場合を下抜けとします。

観測は午前09:00〜11:30、午後12:30〜15:25の同じ連続取引セッション内に限ります。11:30と15:25の足は対象外です。シグナル、開始足、観測終端が昼休み・翌日をまたぐ組み合わせは採りません。過去の特徴量窓は当日内の取引足順で計算し、昼休み前の足も参照できます。昼休みを欠損足とは数えません。欠損足を架空の価格や出来高で埋めません。移動窓は必要な実足が揃ってから回復できますが、当日VWAPは途中の欠損後、その日の残りを不明として扱います。

観測開始から終端まで、必要な各足の始値が有効で出来高が正であることを確認します。未来の高値・安値・終値は、この先の価格観測の可否判定には必要としません。観測終端の価格がない場合は欠損として残し、都合のよい別の足へ置き換えません。入力失敗と観測不能は監査CSVとステータスで区別します。一部銘柄の失敗があっても読めた銘柄の成果物を保存します。読める入力がない場合は失敗終了し、プログラムの例外も成功として隠しません。

観測のステータスは、有効な `valid`、セッション境界を越える `entry_session_boundary` / `horizon_session_boundary`、開始足・途中足・終端足それぞれの `missing` / `invalid_open` / `no_volume` を区別します。未観測の損益はゼロではありません。

全体判定は、入力の欠落・読み取り失敗や、予定取引足の欠損・重複・不正値・出来高ゼロがあれば `partial_success`（一部成功）です。有効な観測を一件も得られない場合、または読み込めた銘柄がない場合は `failed`（失敗）として、可能な成果物を保存した後に終了コード1を返します。それ以外は `success` です。予定日付は全入力で観測された日付の和集合を使い、公式取引日カレンダーとの照合は行いません。全銘柄で丸ごと欠けた取引日は、この方法では検出できません。

## 対照と集計の読み方

対照は同じ銘柄・日付・観測開始の30分時間帯・観測時間・イベント判定に必要な特徴量が揃う条件から、固定シード `20261108` で選びます。イベントが発生した時刻も対照候補に含めます。未来の観測価格が欠けていても引き直しません。対照は約定可能性や無作為な銘柄選定を保証するものではありません。

同じ層の対照は重複なしで抽出します。`time_of_day` は全適格集合そのものをイベントにし、その同じ集合を対照として並べ替えるため、同じ時間帯・観測時間のイベントと対照の集計平均は構造上一致します。一方、個々の対応付けは任意の並べ替えなので、片側だけ観測不能になる組もあり、ペア差から人工的な差が生じ得ます。このため `time_of_day` のペア差平均と日別ペア差平均は未定義（空欄）とし、`paired_comparison_status=not_applicable_same_universe` を付けます。件数は監査用に残します。集計平均の一致を時間帯効果がない証拠や、対照への優位性の検定結果とは扱いません。

価格変化率のマイナスは値下がりを表します。空売り方向の粗損益はその反対符号です。100株は金額換算の参照数量にすぎず、共有資金100万円や建玉上限の下で発注できたことを意味しません。費用控除後の損益も仮定計算であり、実際の貸株在庫・貸株料・逆日歩・空売り価格規制・売買停止・注文板・約定を再現していません。

集計はイベント種類・観測時間・開始時間帯（全時間帯の `ALL` を含む）・費用シナリオで分けます。費用シナリオは費用ゼロ、仮定費用＋片道1円、仮定費用＋片道2円のスリッページです。価格変化率と空売り方向の参照収益率・参照損益の平均や中央値、値下がり割合を示します。成立候補件数（trials）と観測完了件数（observed）を分け、coverageは後者÷前者です。欠損をゼロとして平均に含めません。`time_of_day` 以外はイベントと対照が双方観測できた組だけで空売り方向の差を計算し、`paired_comparison_status=descriptive_matched_difference` とします。因果効果の推定や有意差検定ではありません。

同じ銘柄や時間帯に重なる観測を独立した取引として合算して口座損益と解釈しないでください。集計には銘柄・日の組数、日数、日ごとに平均してからの差も残しますが、ブートストラップ・信頼区間・p値は算出しません。件数が多いだけで統計的な独立性や有意性は保証されません。イベント間の単純な順位を「最も儲かる戦略」と解釈しません。

平均・中央値は観測できた区間に限った記述値です。欠損が価格変動や流動性と関連する場合、その値にも選択バイアスが残ります。特徴量の準備条件によってイベントごとの対象区間も異なります。日付は入力に現れた日の和集合を使い、取引所の祝日カレンダーは照合していません。全銘柄で丸一日欠けた営業日は、この入力だけでは識別できません。
