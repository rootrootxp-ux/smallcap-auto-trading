# yfinance 終値取得テスト（引け後レポート向け）

この機能は**株価取得の疎通確認専用**です。既存の自動売買・バックテスト・約定処理・投信集計・ChatGPT定期配信には接続しません。証券注文は一切行いません。

## 確認内容
- 国内株15銘柄（証券コードに .T を付与）の当日・前営業日の日足終値
- 日経平均 (^N225)、TOPIX (^TOPX) の日足終値
- 前営業日比の値幅と騰落率
- 17銘柄・指数すべてが揃ったか、前日・当日の取引日が一致するか、未来・古い日付や価格欠損がないか

yfinance で auto_adjust=False、interval=1d の Close を使用します。Yahoo Finance経由の**非公式データ**なので、数字が取れても、取引所の公表値等で照合するまで最終確定値と扱わないでください。株式分割・権利落ち・上場廃止等に伴う系列修正の可能性があります。

## 実行
- PR作成・更新時は、関連ファイルが変更された場合に GitHub Actions の **Close price probe (Yahoo Finance)** が実行されます。
- main にワークフローが取り込まれた後は、GitHub の **Actions → Close price probe (Yahoo Finance) → Run workflow** から手動実行できます。
- 研究・検証のため、現段階では定期実行 (schedule) を設定していません。

## 確認方法
GitHub Actions の該当実行で、price-probe ジョブの概要とアーティファクト closing-price-probe を確認してください。アーティファクトの保存期間は14日間です。

- prices.csv: 確認できた銘柄の終値・前営業日終値・騰落率
- status.json: 取得日時（日本時間）、成功/失敗、欠測や日付不一致の理由
- report.md: 一覧とエラー概要

1件でも不足・不整合があれば実行は失敗（赤）となり、推測で補いません。通信・Yahoo側のエラーでも失敗します。投資信託の基準価額、保有株数、円建て評価額はこのテストの対象外です。

**重要:** GitHub Actions の成果物がChatGPTの定期タスクに自動転送されるわけではありません。引け後レポートとの自動連携は別工程です。
