# 50銘柄への研究対象拡大（2026-11-03選定）

## 選定方法と保存物

現在候補は `watchlist.csv` の50銘柄です。バックテスト中に銘柄を再選定しません。
上場廃止4449・5585・5595は現在候補から除外しました。後継464Aは独立した別証券として選定され、5595と価格を連結しません。
590Aも別証券としてプールに含めましたが、今回の順位では採用していません。

事前固定した140社の手動研究プールに、次の基準を適用しました。

1. JPX 2026-09-30国内株一覧に存在し、2026-11-03までに廃止されたコードでないこと。
2. 観測時点の時価総額50億〜1兆円。これは研究上の小型・中型の定義で、JPXの規模指数区分そのものではありません。
3. 直近20本の日足があり、平均 `Close×Volume` が1億円以上、平均 `(High−Low)/Close×100` が2%以上。
4. 通過90銘柄を平均売買代金の降順、同値はコード順で並べ、先頭50を採用。

損益、勝率、5分足品質、建玉単位の購入可否は選定に使っていません。順位が低い銘柄を利益の出た銘柄と入れ替える処理もありません。
母集団は全日本株ではなく、IT・半導体・バイオ・素材・造船・小売等を含む手動プールです。
選定日足は2026-10-05〜11-02、選定日時と時価総額の観測日時は各CSV行に保存しています。

`data/universe50/` に以下を保存しました。

- `candidate_pool.csv`：140社の候補名・業種・プール選定理由。
- `pool_audit.csv`：採否の根拠となった日足指標・時価総額・取得失敗。
- `selection_policy.json`：閾値・順位方法・選定件数・ハッシュ。
- `selection_inputs.zip`：取得した日足と時価総額の観測情報（銘柄別SHA-256付き）。
- `jpx_listing_20260930.xlsx`：JPX国内株一覧の原本。
- `delisted_asof_20261103.json`：公式廃止一覧から、確認日以前の廃止だけを抽出。

## 選択バイアスと資金モデル

現在の存続情報・時価総額・11月2日までの日足で選んだ50銘柄の過去成績は、事後選定の記述分析です。
JPX一覧自体の基準日も過去の5分足検証開始日より後です。したがって先読み・生存者・手動プールの選択バイアスがあります。
`bias_audit.csv` は各銘柄について、検証開始日以降の日足を選定に使ったかを機械判定します。
開始日**より前**の日足だけで同じ流動性条件を判定し、採否と部分集合の成績がどう変わるかを感度点検します。
全140候補の順位点検では、2026-09-16より前の日足を使うと共通43銘柄、各7銘柄の入替となりました。現在の存続・時価総額は固定しているため、この点検も真の当時の母集団・未参照データ検証ではありません。先行側のみ7銘柄の5分足成績は計算しておらず、入替後利益を推定しません。
選定後の将来期間は別途蓄積が必要です。既存期間の分割や、現在候補に対する過去の閾値再判定をOOSと呼びません。

**各銘柄に100万円を独立配分しています。全50銘柄共通の100万円口座ではありません。**
同時保有の資金競合、銘柄間の注文優先順位、ポートフォリオの損益・最大DDは再現していません。
資金を実際に5000万円投入した口座の再現とも限らず、独立した仮定の集合です。実注文・証券会社接続はありません。
